## Selected work

### VideoLinksVault

Live product. A free video bookmark vault. Members save a link, play it on-site, and keep a library. Guests can browse public items. Capture requires an account.

- Live: [videolinksvault.com](https://www.videolinksvault.com)
- Stack: TypeScript, TanStack Start, Better Auth, Postgres, Vercel
- Repo is private. Code review available on request.

What I own: the product, the auth and access rules, capture and playback, public discovery, ads, and production deploys.

### NobleLogic CLIP API

A maintained CLIP embedding API. Text and image embeddings over HTTP, without making the caller run a GPU.

- Public API surface: [clip-api-public](https://github.com/NobleLogic1/clip-api-public)
- FastAPI edition: [clip-maintained-api](https://github.com/NobleLogic1/clip-maintained-api)
- Landing: [clip-maintained-landing](https://github.com/NobleLogic1/clip-maintained-landing)
- Hosted: [noblelogicllc.com](https://noblelogicllc.com)

- [keel-prototype](https://github.com/NobleLogic1/keel-prototype)
